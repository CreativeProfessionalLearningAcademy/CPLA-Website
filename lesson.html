The problem you're about to solve
Most designers pick up the Pen tool before they understand what it draws
The problem

Students try to operate the Pen tool before they understand what it produces. The cursor drops points that don't connect, curves flip the wrong direction, handles appear from nowhere. It feels broken — and it keeps feeling broken until the underlying structure is visible.

The solution

Slow down before opening the Pen tool. Once you can see a path the way a professional sees it — as a small set of points with predictable behavior — every Pen tool action becomes logical rather than mysterious.

Section 1 — Before the tool, the logic
Everything in Illustrator is a path

In Module 2 you set up the environment — the workspace, the document, the layers. You built the room. This module is about the material you will work with inside it: the path. Every vector object in Illustrator is a path or a collection of paths. A logo is paths. A letterform is a path. A map, an icon, a packaging dieline — all paths. There is no separate thing to learn for each; there is one underlying structure, repeated.

This is why we slow down before opening the Pen tool. You already met the reason in Lesson 2.3: the curves you are about to draw come directly from Pierre Bézier's 1960s mathematics. Now you will see that math as something you can hold.

Section 2 — The three parts of every path
Anchor points, segments, and direction handles

An anchor point is a single fixed location that the path passes through — the skeleton of the shape. Place two anchor points and connect them and you have the simplest possible path: a single straight line. Anchor points are what you click into existence with the Pen tool, and what you grab and move with the Direct Selection tool (the white arrow).

A segment is the line that runs between two anchor points. A segment is either straight or curved — there is no third kind. A path is simply an ordered chain of anchor points joined by segments. When a designer says a shape has "too many points," they mean the chain is longer than it needs to be.

A direction handle is the lever that bends a segment into a curve. Handles extend out from an anchor point like antennae. Their length and angle determine how the curve leaves and enters that point. A straight segment has no active handles; a curved segment is shaped by the handles on both anchor ends. The Pen tool's click-and-drag is nothing more than placing an anchor and pulling out its handles in one gesture.

The whole vocabulary in one sentence

A path is an ordered set of anchor points, joined by straight or curved segments, whose curves are shaped by direction handles. That is the entire structure. Every drawing you make for the rest of this program is built from these three words.

Section 3 — Open and closed paths
The type of path determines what it can do

Every path is one of two kinds. An open path has two distinct endpoints that are not joined — a single line, an arc, a signature stroke. A closed path loops back on itself with no endpoints — a circle, a star, the outline of a letter. The practical consequence is about fill: only a closed path encloses an area, so only a closed path can hold a fill color reliably.

Drawing a leaf? That is a closed path — it needs to hold a green fill. Drawing the stem as a thin line? That can be an open path with a stroke. Knowing which kind you are making before you start prevents the most common beginner confusion: trying to fill a shape that never actually closed.

Section 4 — Corner and smooth points
The distinction that makes the Pen tool predictable

A corner point creates an abrupt change of direction — the path can turn sharply, like the tip of a star or the corner of a rectangle. A smooth point creates a continuous, flowing transition — the path glides through it without a kink, like the side of an ellipse. At a smooth point the two handles act as one straight lever, keeping the curve continuous. At a corner point the handles are independent, so the path can break direction.

You will spend the next two lessons learning to place each kind deliberately and to convert one into the other. For now, the goal is only to see the difference: open any vector shape, switch to the Direct Selection tool, and click a point. A smooth point shows two handles in a straight line through it; a corner point shows handles that angle independently.

Section 5 — Why it matters
Vector paths are resolution-independent

When Illustrator saves a path, it does not save a picture of the path. It saves the recipe: the coordinates of each anchor point, the lengths and angles of the direction handles, and the order they connect. That recipe is mathematics, and mathematics has no size. When you scale the shape to 10 times its size or 1/100th, Illustrator recalculates the same recipe at the new dimensions. The edge stays perfectly crisp because there were never any pixels to blur — there were only points and the math between them.

This is the entire reason vector is the right tool for logos, icons, type, and anything that must survive scaling. A raster image stores pixels and degrades when enlarged; a vector path stores a recipe and is indifferent to scale.

Path discipline starts here

In Module 1 you heard senior designers give the same note again and again: "simplify the paths." Now you can see what they mean. Fewer anchor points means a shorter recipe, a smoother curve, a smaller file, and a shape anyone can edit. Use the fewest anchor points that describe the shape cleanly. A curve that needs eight points from a beginner needs two or three from a professional.

Key vocabulary — Lesson 2.9
Eight terms. Know them cold.
Anchor Point
A single fixed coordinate that a path passes through — the skeleton of a vector shape. Created with the Pen tool, edited with the Direct Selection tool.
"This curve has six anchor points doing the work of three — pull out the middle ones."
Path
An ordered chain of anchor points joined by segments. The fundamental object of all vector drawing in Illustrator.
"The whole logo is one closed path — there's nothing to group."
Segment
The line connecting two adjacent anchor points. Always either straight or curved — never both.
"That segment is curved where it should be straight — flatten the handles."
Direction Handle
The lever extending from an anchor point that controls how a curved segment bends. Its length and angle shape the curve.
"Shorten the handle and the curve tightens into the corner."
Open Path
A path with two unjoined endpoints — a line or stroke. Cannot reliably hold a fill because it encloses no area.
"The stem is an open path — just stroke it, don't try to fill it."
Closed Path
A path that loops back to its start with no endpoints — a shape. Encloses an area and can hold a fill.
"Close the path before you fill it, or the color won't behave."
Corner Point
An anchor where the path changes direction abruptly. Its handles act independently, allowing a sharp turn.
"The star tips are corner points — sharp, not rounded."
Smooth Point
An anchor where the path flows through continuously without a kink. Its two handles align as one lever.
"Make that a smooth point so the curve doesn't pinch."

Design Brief — Lesson 2.9

Path Anatomy Study + First Minimal Traces

The problem

You cannot draw a path well until you can read one. First you'll dissect existing vector shapes to see their structure, then create your own paths under one constraint — the fewest anchor points possible.

Constraints
  • Part A — Read. Open the anatomy template. Label each anchor as corner or smooth, and each path as open or closed.
  • Part B — Build. Trace three silhouettes (leaf, speech bubble, lightning bolt) using only straight segments. No curves yet.
  • Record anchor-point count for each trace. Try removing one — keep the lowest count that still reads as the shape.
Your deliverable

One .ai file · two artboards: (1) labeled anatomy template, (2) three traced silhouettes with anchor counts.
