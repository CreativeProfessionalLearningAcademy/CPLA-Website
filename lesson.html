Section 1
Before the tool, the logic

Every vector object in Illustrator is a path or a collection of paths. A logo is paths. A letterform is a path. There is one underlying structure, repeated everywhere.

The whole vocabulary in one sentence

A path is an ordered set of anchor points, joined by straight or curved segments, whose curves are shaped by direction handles. Every drawing you make for the rest of this program is built from these three words.

Design Brief — Lesson 2.9

Path Anatomy Study + First Minimal Traces

The problem

You cannot draw a path well until you can read one. First you'll dissect existing vector shapes to see their structure, then create your own paths under one constraint — the fewest anchor points possible.

Constraints
  • Part A — Read. Open the anatomy template. Label each anchor as corner or smooth, and each path as open or closed.
  • Part B — Build. Trace three silhouettes (leaf, speech bubble, lightning bolt) using only straight segments. No curves yet.
  • Record anchor-point count for each trace. Try removing one — keep the lowest that still reads.
Your deliverable

One .ai file · two artboards: (1) labeled anatomy template, (2) three traced silhouettes with anchor counts.
