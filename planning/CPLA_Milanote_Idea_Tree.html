Milanote Partnership — Idea Tree

A structured look at a possible tool partnership, seeded by the MACC pilot (where students already hold paid seats) — deliberately kept decoupled from the curriculum so it stays optional for everyone else.

Root Idea
CPLA × Milanote
A creative-workspace partnership — showcase for them, polished submission home for us.
1Why It Fits
  • Same audience — creative students doing exactly the visual-thinking work Milanote is built for.
  • MACC students already have paid seats, so there's real classroom usage from day one.
  • Natural co-marketing: a genuine case study and joint content.
2What CPLA Would Ask For
  • Education SSO via school email (absent today).
  • Account + board-link provisioning API (no public API today).
  • Discounted or sponsored education seats for partner schools.
3What Milanote Would Gain
  • A growing CTE curriculum as a showcase and user pipeline.
  • Creative users onboarded young, with habits formed early.
  • Proof: a real classroom pilot testimonial and case study.
4Partnership Models — light → deep
  • Recommended tool + co-marketing (lightest).
  • Education licensing: discounted / sponsored seats.
  • Technical integration: SSO + provisioning API.
  • Referral or revenue share (most formal).
5Risks & Guardrails
  • Vendor dependence → submission method stays a config option, never in a lesson.
  • Neutrality — some schools use other tools, so Milanote stays optional.
  • Pricing / policy shifts → never bake the tool into curriculum.
  • No API / SSO today → integration depth is limited until they build it.
6Low-Regret Next Steps
  • Run the MACC pilot on Milanote; gather real usage evidence.
  • Write a one-page case study from the pilot.
  • Approach Milanote's education / partnerships team with the proof.
  • Lead the ask with SSO + provisioning API.
⚿
Guardrail. Submission method is an organization configuration setting — never curriculum. The lesson says "submit your deliverable"; the platform decides how. Milanote stays swappable, so this partnership is pure upside with no lock-in — and the day a vendor name creeps into lesson content is the warning line.
