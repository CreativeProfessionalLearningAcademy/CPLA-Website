Volume 2 — Illustrator / Module 3 of 5

Paths, Shapes & Vector Control

Every object in Illustrator is a path. Before a student can operate the Pen tool with confidence, they must be able to see what a path actually is — its anchor points, direction handles, and segments. This module takes you from that first structural understanding through the hands-on construction of real vector shapes, using a cloud form as the guided study.

What this module covers
Anchor Points
The fixed coordinates that define every shape. Corner vs. smooth points and when to use each.
Direction Handles
The levers that bend segments into curves — their length and angle determine curve quality.
The Pen Tool
Click for corners, click-drag for smooth curves. Option/Alt to break handles independently.
Direct Selection
Edit individual points and handles after drawing — the tool that refines every path.
Compound Paths
Combine shapes to punch holes, create letterforms, and build complex outlines.
The Cloud Study
The module's guided project — a complete vector form built from scratch using Pen tool technique.
