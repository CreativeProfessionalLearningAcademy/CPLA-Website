Typographic Hierarchy

Bringing Module 4 together into a reading order
The Big Idea
This is where Module 4 comes together. Classification gives type its voice, anatomy gives you control, pairing gives you a system — and hierarchy organizes it all into a clear reading order. Typographic hierarchy is the practical skill of making a multi-level text layout instantly navigable using type alone.
What you're really teaching
  • Hierarchy failure is the most common text-design problem, and it almost always comes from timid differentiation — size gaps too small, weight too subtle, spacing too uniform. The fix is to make the differences dramatic and systematic.
  • Four tools build hierarchy: size, weight, style, and space. Style variation — italic, small caps — can signal a distinct role without adding another typeface.
  • Use a type scale, not arbitrary sizes. A base size and a ratio generate harmonious, clearly distinct steps — base 16 at a 1.5 ratio gives 16, 24, 36, 54.
  • Define the levels before laying out. H1, H2, body, caption — each with its own size, weight, style, leading, and spacing, assigned to a step on the scale.
  • The squint test verifies it. Blur the layout: the headline should still dominate and the levels stay distinguishable. If everything looks the same blurred, the hierarchy isn't working.
Scenarios & hooks to open the room
Five levels, one size

Headline, subhead, body, pull quote, caption — all barely different. The hierarchy is present but perceptually invisible.

The type scale

Base 16 at a 1.5 ratio versus sizes chosen by eye. The scale produces clean, distinct, related steps.

Style variation

Pull quotes in italic, captions in small caps — distinct roles signaled without a new typeface.

The squint test

Blur the layout and ask: does the headline still lead? If not, the differentiation is too timid.

Teaching the lesson — step by step
Hook: which one is the headline? 5 min

Show five near-same-size levels and ask students to spot the headline at a glance. They can't — timid differentiation, felt.

The four tools and timid differentiation 10 min

Size, weight, style, space — and why beginners under-differentiate every one of them.

Build a type scale 8 min

Base plus ratio; generate four steps; show why a scale beats arbitrary sizes.

Define the four levels 8 min

H1, H2, body, caption with size, weight, style, and leading each — integrating pairing and anatomy (1.4–1.6× leading, 50–75-character lines).

Set up the capstone 6 min

A real layout with a pairing, a scale, a four-level spec, and a squint test.

Close with a live squint 5 min

Squint at a projected student layout together and name any level that fails.

Facilitating the Field Manual — Typographic Hierarchy Capstone
Running the exercise

Students integrate all of Module 4 into one working type system on a real multi-level layout.

  • Choose a genuinely multi-level layout — an article spread, program, newsletter, or product page — so hierarchy has real work to do.
  • Select a pairing with a Lesson 1.14 strategy and justify it for the content's voice.
  • Build a real type scale — a base size and a ratio generating at least four sizes — rather than choosing sizes by eye.
  • Specify all four levels — size, weight, style, leading — and apply 1.4–1.6× leading and 50–75-character lines from the anatomy lesson.
  • Run the squint test and revise any level that fails; the verification note is part of the deliverable.
The Assignment & Deliverable — Typographic Hierarchy — Module 4 Capstone
What good work looks like

A complete layout with a documented type system: pairing, scale, four-level spec, and squint-test note.

  • Meets the bar: a documented pairing with rationale, a type scale, a four-level specification, and a squint-test note.
  • Exceeds: the differentiation is dramatic, the squint test cleanly passes, and leading and line length are correctly applied.
  • Redirect: timid size gaps between levels — double them and re-run the squint test.
Watch for
  • Timid differentiation. The root cause of hierarchy failure — demand dramatic, systematic gaps.
  • Arbitrary sizes instead of a scale. No harmony, and the steps read as unclear.
  • Forgetting leading and line length. Hierarchy fails if the body itself is uncomfortable to read.
  • Skipping the squint test. It's the check that catches perceptually invisible hierarchy.
Discussion questions
  • Why is timid differentiation the usual cause of hierarchy failure?
  • How does a type scale beat choosing sizes by eye?
  • What can the squint test reveal that careful reading can't?
Lesson objectives
  • Build a complete typographic hierarchy with at least four levels using the tools of type
  • Apply the four typographic hierarchy tools — size, weight, style, and space — to create clear reading order
  • Establish a type scale (a consistent set of sizes) rather than choosing sizes arbitrarily
  • Integrate everything from Module 4 — classification, anatomy, pairing — into one functional system
  • Evaluate a typographic hierarchy with the squint test and correct insufficient differentiation
Key vocabulary
  • Typographic Hierarchy — The organization of multiple text levels into a clear order of importance using size, weight, style, and space — making a layout navigable at a glance.
  • Type Scale — A consistent set of sizes derived from a base size and a ratio — guaranteeing visible, harmonious differences between levels.
  • Hierarchy Level — A distinct tier in the typographic order — H1, H2, body, caption — each with defined size, weight, style, and spacing.
  • Differentiation — The degree of visible difference between levels — sufficient differentiation makes levels distinguishable without reading; timid differentiation fails.
  • Style Variation — Using italic, small caps, or a different family to signal a distinct role — differentiating role rather than just importance.
  • Squint Test — Blurring the view of a text layout to verify the hierarchy is visible — the most important element should dominate even when the words are unreadable.
