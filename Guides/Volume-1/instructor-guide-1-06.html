Visual Hierarchy

Directing the eye through deliberate reading order
The Big Idea
If everything is equally important, nothing is. Visual hierarchy is the system of deliberate size, weight, color, position, and space decisions that creates a reading order — first this, then this, then this — so the viewer never has to work to find the message. Without it, the eye wanders and the message never lands.
What you're really teaching
  • Five tools build hierarchy: size, weight, color, position, and space. Together they set an element's visual weight — its ability to attract the eye.
  • The squint test reveals the truth. Squint until the elements blur; whatever still dominates is what the hierarchy is actually emphasizing. If the decorative border survives and the headline doesn't, that's a hierarchy problem.
  • Three failure modes recur. Equal-weight confusion (no entry point), emphasis overload (everything bold means nothing is bold), and scale timidity (differences too small to see without reading).
  • The fixes are blunt. Make the dominant element dramatically larger — 200%, not 20%. Limit strong emphasis to one or two elements. If you can only tell levels apart by reading them, the size gap is insufficient.
  • Decide the reading order first. Name the sequence — first X, then Y, then Z — before placing a single element, then build the hierarchy to produce exactly that path.
Scenarios & hooks to open the room
Five equal elements

Headline, subhead, body, call to action, and logo all the same size. Ask where the eye lands first — the random answers are the problem.

The squint demo

Project a layout and squint (or blur it) live. Whatever survives the blur is the real hierarchy, not the intended one.

20% vs. 200%

Put a timid size bump next to a bold one. Students feel instantly which one actually creates an entry point.

Emphasis overload

A page where everything is bold and highlighted. Cut back to one primary element and watch emphasis return.

Teaching the lesson — step by step
Hook: where does your eye go? 5 min

Show a flat five-element layout and ask where they look first. Scattered answers prove the absence of hierarchy.

Teach the five tools 10 min

Size, weight, color, position, space — demonstrate each shifting the visual weight of one element on screen.

The squint test 7 min

Demonstrate it live. Whatever survives the squint is what's really being emphasized — often not the headline.

Three failures and their fixes 10 min

Walk equal-weight, overload, and timidity, each with its correction — especially “200%, not 20%.”

Set up the three-version study 6 min

Same five elements, three hierarchy structures: A none, B headline-first, C call-to-action-first. Squint-test each.

Close on fit-to-brief 5 min

Students name which version serves which brief and why the squint evidence supports it.

Facilitating the Field Manual — Hierarchy Study — Three Versions, One Composition
Running the exercise

Students build three hierarchy structures over identical content and test each with the squint test.

  • Fix the five elements — headline, subhead, body, call to action, logo — so hierarchy is the only variable across versions.
  • Version A has no hierarchy, B prioritizes the headline, C prioritizes the call to action. Different reading orders serve different briefs.
  • Apply the squint test to each version and record what dominates — the evidence, not the intention.
  • Push against scale timidity: demand a dramatically dominant element, then re-squint.
  • Tie each version to a goal — which reading order would you choose to drive sign-ups versus build awareness?
The Assignment & Deliverable — Hierarchy Study — Three Versions, One Composition
What good work looks like

Three versions of one composition with distinct hierarchy, plus a squint-test verdict on which serves a brief.

  • Meets the bar: three genuinely different reading orders over identical content, each squint-tested.
  • Exceeds: the student argues which version fits which brief, citing what survived the squint as proof.
  • Redirect: timid scale gets one instruction — make the dominant element 200% larger, then squint again.
Watch for
  • Scale timidity. The dominant element is only slightly bigger. Demand drama, not politeness.
  • Emphasis overload. Bolding or coloring everything. Cap strong emphasis at one or two elements.
  • Skipping the reading-order decision. Placing elements before deciding the sequence they should be read in.
  • Confusing pretty with clear. Hierarchy serves reading order; a nice-looking flat layout still fails the job.
Discussion questions
  • Think of a poster that told you exactly where to look. What made the path so clear?
  • Why is “make it 200% bigger, not 20%” such common advice for beginners?
  • Can a design have strong hierarchy and still be ugly — and does that matter for its job?
Lesson objectives
  • Explain visual hierarchy as a system for directing viewer attention — not an aesthetic preference
  • Apply the five tools of hierarchy — size, weight, color, position, and space — to create a clear reading order
  • Use the squint test to evaluate whether hierarchy is working at a glance
  • Diagnose the three most common hierarchy failures: equal-weight confusion, emphasis overload, and scale timidity
  • Redesign a flat, unhierarchical layout to have clear, functional reading order
Key vocabulary
  • Visual Hierarchy — the system of visual-weight decisions that creates a deliberate reading order.
  • Visual Weight — an element's ability to attract the eye — set by size, weight, color, position, and space.
  • Squint Test — squint until elements blur, then check whether the dominant element is the correct one.
  • Emphasis Overload — too many emphasized elements — destroying the contrast that makes emphasis mean anything.
  • Reading Order — the sequence in which a viewer encounters information, produced by the hierarchy.
  • Scale Timidity — making the dominant element only slightly larger — hierarchy that is technically present but perceptually invisible.
